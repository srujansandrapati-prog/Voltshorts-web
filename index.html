Separate questions.json on GitHub

This app is engineered with a dual-mode database loader (fetch('./questions.json') + embedded 60-question fallback):

  1. Click the blue "questions.json" download button in the left sidebar to save the standalone JSON database file.
  2. Create a free GitHub repository and upload both index.html and questions.json into the same root folder.
  3. Enable GitHub Pages in your repository's Settings → Pages.
  4. Whenever you want to add more questions later, simply edit questions.json directly on GitHub (or use the Add New Question button in this app and re-export questions.json)!
