Separate questions.json on GitHub

This index.html is lightweight and fetches your questions directly from ./questions.json in the same GitHub repository folder:

  1. Keep index.html and your questions.json in the same folder of your GitHub repository.
  2. Enable GitHub Pages in your repository's Settings → Pages.
  3. Whenever you update questions.json on GitHub, click "Sync JSON" in the left sidebar (or refresh) to pull the latest questions immediately.
